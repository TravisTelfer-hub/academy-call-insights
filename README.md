# Academy call insights - encrypted Pages deploy

Password-protected report of what 141 Fathom calls revealed about why people join the Webprofits Academy, plus the growth playbook. Served on GitHub Pages; `public/index.html` is StatiCrypt-encrypted (AES-256) client-side.

- Source report: `../report/index.html` (generated by `../report/build_report.py`)
- `make refresh`  - rebuild the report from the Python generator, copy it in, re-encrypt
- `make encrypt`  - encrypt `public-encrypted/index.html` -> `public/index.html` with `PAGE_PASSWORD` from `.env`
- `make verify`   - decrypt the output and diff it against the source
- `make publish`  - encrypt, commit, push (Actions deploys `public/` to Pages)

The password is fixed (not HMAC-derived) so the team can remember it. It lives only in `.env` (gitignored).

`public-encrypted/` is gitignored: the repo is public, so only the encrypted `public/` is ever committed. The plaintext source lives locally in `../report/`.
